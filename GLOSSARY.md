# Glossary

- **Presentation metadata**: Optional information that describes an element's reveal timing and, when present, its semantic style role.
- **Presentation stylesheet**: CSS supplied by a presentation to style a diagram while it is rendered; it can apply generally or target semantic style roles without changing the source drawing.
- **Reveal step**: An element's position in a presentation's reveal sequence. Step 0 is visible initially; elements with the same positive step appear together.
- **Semantic style role**: An optional label describing how an element should be styled by a presentation. If no matching style is available, the element's original appearance is used.
